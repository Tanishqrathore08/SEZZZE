🚀 Reality By Design (SEZZZE)

🚀 Overview

Reality By Design (SEZZZE) is an immersive, next-generation web experience that transforms a traditional website into an interactive digital environment.

Instead of static scrolling, it allows users to explore content through motion, depth, and real-time interaction, creating a more engaging and futuristic browsing experience.

 💡 Why I Built This
Most websites today feel static and predictable.
So I built this project to:

* Create a more immersive and interactive user experience
* Explore the power of 3D and motion in web design
* Push beyond traditional UI/UX patterns
* Combine creativity with modern frontend technologies

## ⚙️ How It Works

### 🎯 3D Interaction System
* Displays a **3D sneaker model (.glb)**
* Responds to mouse movement with smooth rotation
* Creates a sense of depth and realism

 🖱️ Custom Cursor System
* Replaces default cursor with a dynamic element
* Smooth trailing animation using GSAP
* Magnetic hover effects for interactive elements

### 🎬 Scroll & Animation Engine
* Smooth scrolling using Lenis
* Scroll-triggered animations with GSAP
* Parallax effects for depth illusion

### 📱 Responsive Design
* Adapts layout for mobile and desktop
* Dynamic camera positioning for 3D elements
* Maintains visual consistency across devices

## 🔥 Features
